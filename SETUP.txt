Mood Minder — install on another Windows PC
===========================================

You have two ways to put this app on another computer.


OPTION A — Easy installer (uses Python)
---------------------------------------
1. Copy the whole Mood Minder / project folder to the other PC
   (USB drive, zip file, OneDrive, etc.)

2. On that PC, double-click:  install.bat

3. If Python is missing:
   - The installer opens https://www.python.org/downloads/windows/
   - Install Python 3.10 or newer
   - Check "Add python.exe to PATH"
   - Run install.bat again

4. When install finishes:
   - Use the Desktop shortcut "Mood Minder"
   - Or double-click run.bat


OPTION B — Standalone EXE (no Python on the other PC)
-----------------------------------------------------
Build this once on a PC that already has Python:

1. Double-click:  build_standalone.bat
2. Find:  dist\MoodMinder.exe
3. Copy ONLY MoodMinder.exe to the other PC
4. Double-click the EXE to run


Minimum files for Option A
--------------------------
  app.py
  mood_engine.py
  pdf_export.py
  requirements.txt
  install.bat
  install.ps1
  run.bat
  SETUP.txt


Notes
-----
- Windows 10/11 recommended
- Journal data is stored locally as mood_log.json / mood_settings.json
- Personal pattern journal only — not a medical diagnosis
- If you are in crisis, seek professional help
